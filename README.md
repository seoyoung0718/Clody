# 📓 Log-in

> Log-in: 그룹 다이어리 웹 서비스

Log-in은 여러 사람이 함께 일기를 작성하고 공유할 수 있는 그룹 기반 다이어리 웹 서비스입니다.
친구, 동료, 스터디 등 다양한 모임에서 각자의 하루를 남기고, 서로의 이야기를 나누며 소통할 수 있는 공간을 제공합니다.

## ✨주요기능

### 📓 그룹 다이어리 생성
- 사용자는 새로운 그룹 다이어리를 생성
- 다이어리 제목과 소개글을 설정하여 다이어리 공간을 구성  

### 🔍 제목 기반 다이어리 검색
- 다이어리 제목을 기준으로 검색 가능  
- 검색 결과를 통해 원하는 다이어리를 빠르게 조회 가능  

### ✍️ 일기 작성
- 다이어리 멤버로 참여한 사용자는 자신의 일기 작성 가능
- 작성된 일기는 같은 다이어리 멤버들과 공유
